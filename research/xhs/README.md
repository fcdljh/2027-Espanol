## 研究范围与计数

只研究巴塞罗那、格拉纳达、塞维利亚。马德里可作为机场或转机城市，不作为旅游城市研究。

每城六个子分类各收集至少 10 篇，合计至少 **60 篇/城、180 篇/三城**：

1. Citywalk 与街区路线
2. 人像、风景及经典拍照机位
3. 建筑、历史街区与经典景点动线
4. 市内交通、机场/车站进城
5. 美食、市场、咖啡馆与本地日常
6. 住宿区域与居住体验

仅当小红书笔记详情页成功打开，并实际读到正文或图文/视频中的攻略内容，才计为完整阅读。搜索卡片、标题、摘要、网页搜索片段、打不开的笔记均不计数。部分读到的笔记记录在“部分阅读”，不抵分类配额。

## 搜索约定

每条基础搜索词只表达一个检索意图，先用“城市名 + 子分类”扩大召回，不预先加街区、景点或时间筛选。只有基础词的结果不足以完成该类配额时，再按实际缺口添加街区或具体需求；区域词是补充搜索，不是默认条件。不要把住宿、交通、拍照和路线合并到同一条搜索词。比如：

- Barcelona：`巴塞罗那 Citywalk`；`巴塞罗那 住宿`；`巴塞罗那 交通`；`巴塞罗那 拍照`；`巴塞罗那 建筑历史`；`巴塞罗那 美食`。
- Granada：`格拉纳达 Citywalk`；`格拉纳达 住宿`；`格拉纳达 交通`；`格拉纳达 拍照`；`格拉纳达 建筑历史`；`格拉纳达 美食`。
- Seville：`塞维利亚 Citywalk`；`塞维利亚 住宿`；`塞维利亚 交通`；`塞维利亚 拍照`；`塞维利亚 建筑历史`；`塞维利亚 美食`。

补充搜索再针对实际缺口细化，例如 Citywalk 可搜某个已识别街区的路线，交通可分别搜机场/车站接驳或市内交通；不能因为某类有许多景点集中在一处，就把首轮搜索限定到那个区域。

搜索结果只用于发现候选笔记。记录每次实际使用的搜索词和日期；打开候选笔记后，先以笔记 ID 去重，再读内容并更新城市文件和配额。优先保留亲历路线、街区细节、拍摄位置/时段、交通操作和个人踩坑，不因点赞数或标题看起来全面就代替阅读。

## 交叉核对

同一地点、路线、交通卡、营业时间、票价或住宿区域建议出现不同说法时，在对应城市文档列出各笔记 ID 和原说法；对争议点另开一条窄搜索。运营信息再以景点、交通机构、市政部门或场馆官方信息核实，并注明来源及核对日期。小红书经验用于路线与氛围灵感，不单独作为实时运营规则的依据。
