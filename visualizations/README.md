# 可视化产物

本目录只存由研究数据生成的图表和报告，不作为价格、行程或运营事实的原始来源。用户可见的图表标题、注释和说明使用中文；脚本、字段名等技术内容可保留英文。

## 生成与复核规则

- 每个产物旁都要保存一个 `*.manifest.json` 清单，注明生成日期、输入文件和 `record_id` 范围、筛选条件、时间区间、币种及换算方式、生成脚本与命令；模板见 [`ARTIFACT-MANIFEST-TEMPLATE.md`](ARTIFACT-MANIFEST-TEMPLATE.md)。不要只留一张脱离数据口径的图片。
- 可复现流程为：结构化研究数据 → 版本控制中的生成脚本 → 产物与 manifest。更新数据或脚本后重新生成产物，不直接修改生成文件。
- 机票趋势要比较同类往返查询。至少明确出发地、目的地/路线、出发与返程日期、旅客数、舱位、两程托运行李条件、税费口径和来源。邻月参照、市场基准和实际行程查询要分组显示。
- 若记录的日期、乘客数、路线、行李或税费条件不一致，分开展示或排除，并说明原因。`unverified` 与 `expired` 数据不得显示为当前可买价格；样本不足时明确标注，不插值或外推成趋势。
- 货币换算保留原始金额，并注明汇率日期、方向和来源。禁止用估算换算替换平台原币报价。
- 生成图表前先查看对应的研究规范和 CSV；输出文件不得反过来成为事实源。修改图表时同步更新生成说明，并抽查图中的记录和数值是否来自输入数据。

## 地图数据位置

三城交互地图仍位于 [`research/city-maps/`](../research/city-maps/README.md)，不是本目录的独立事实表。该地图以 `research/city-maps/city-data.js` 为长期结构化数据源，`city-atlas.html` 为查看器；目录中的 `three-cities-orientation.kml` 是空文件夹模板。页面导出的 KML 属于衍生输出，新增或修改长期地图内容时应编辑 `city-data.js`。
