# 西班牙三城小时级执行攻略

最后整理：2026-10-11。给第一次走 Barcelona、Granada、Seville 的旅伴使用。当前结构是 **阿联酋航空北京→Dubai→Barcelona 往返**，西班牙境内为 **Barcelona → Granada → Seville → Barcelona**；全程不安排 Madrid。

国际段时刻、票价、北京机场、Dubai停留和行李以出票页为准。时刻变化只影响 D1 的恢复模块和 D9 的机场出发时间，不自动平移城市日期。

## 先记住五条规则

1. 到达日先入境、取行李、入住和补给；没有余力就删除散步。
2. 长途日先交通，再入住/寄存、吃饭、充电，最后才决定轻量短线。
3. Sagrada Família、Alhambra、Alcázar、Cathedral 是四个预约/建筑核心。
4. D8 必须白天从 Seville 到 Barcelona 并住一晚；D9 不从其他城市跨城接国际航班。
5. 所有车票、住宿和门票都是候选，最终以官方/供应商页面为准；不把搜索结果当成预订。

## 交通总卡

- **D1：**BCN机场到最终住宿。先完成入境和取行李，再用 Aena/TMB 或正规出租车；不在到达日购买/衔接城际票。
- **D4：**Barcelona Sants→Granada。Renfe优先，航班需把机场往返、安检和行李计入；抵达后中心平地短线。
- **D6：**Granada→Seville。Renfe优先，ALSA备选；入住后可做西班牙广场短线。
- **D8：**Sevilla Santa Justa→Barcelona Sants。Renfe优先，必要时比较 SVQ→BCN；住Sants或机场交通便利区域。
- **D9：**住宿→BCN机场。按最终国际航班倒推，国际航班约提前3小时到机场；确认航站楼和行李条。

## 逐日执行

### D0｜1月25日：北京集合与国际出发

| 时间 | 做什么 | 备注 |
|---|---|---|
| 出发前 | 三人核对护照、签证、保险、阿联酋航空出票页和行李额度 | 每个实际航段至少20kg行李需有证据 |
| 到机场 | 确认北京具体机场、航站楼、值机柜台和三人是否同一订单 | 未提供的航班号/时间不自行补写 |
| 转机 | 北京→Dubai→Barcelona，按航司与机场指引行动 | 不把Dubai转机当作可自由出机场时间 |
| 机上 | 睡眠、补水、保存Barcelona住宿地址 | 不安排抵达日预约 |

### D1｜1月26日：Barcelona入境恢复日

| 时间 | 做什么 | 删除条件 |
|---|---|---|
| 落地–H+1:30 | 入境、取行李、确认三人集合和行李 | 排队/行李异常时不赶任何活动 |
| H+1:30–H+2:15 | BCN→住宿 | 只用确认过的机场交通；不临时跨城 |
| H+2:15–H+4 | 入住或寄存、洗漱、确认门禁和Wi‑Fi | 不能入住就先联系住宿方并保持集合 |
| H+4–H+5 | 买水、早餐、次日早餐和简单晚餐 | 晚到则用住宿附近/外卖 |
| H+5后 | 体力允许时住处/Sants附近短走30–60分钟 | 约18:00后、下雨或疲劳就直接休息 |
| 睡前 | 打开Sagrada票券，确认入口、时段和三人姓名 | 不为第二天票券临时跨区 |

### D2｜1月27日：Sagrada Família → Sant Pau

- 出发前：确认实名票、入场时段、天气和衣物；早餐后提前到入口。
- 上午：Sagrada Família 室内与外观，按官方动线，不在入口长时间停留。
- 午间：Avinguda Gaudí 平地移动，回住宿或附近坐下休息。
- 午后：Sant Pau，重点拍建筑细节、拱廊和三人合影。
- 傍晚：按体力在附近吃饭；不再叠加 Casa Batlló、Park Güell 或山上景点。
- 雨天：保留已购室内部分，删除外围长时间拍摄。

### D3｜1月28日：Gothic/Born + Passeig de Gràcia

- 上午：Gothic 老城平地线，Carrer del Bisbe、广场和街区关系按体力取舍。
- 午餐后：Born、Santa Caterina 或 Arc de Triomf/Ciutadella 选择一段，不全打卡。
- 下午：Passeig de Gràcia 看 Casa Batlló、La Pedrera 外观；最多选择一座室内建筑。
- 晚间：回住宿整理行李，确认 1/29 车票、车站和 Granada 地址。
- 雨天：缩短街拍，保留一座已购室内建筑或老城室内餐饮。

### D4｜1月29日：Barcelona → Granada

| 时间 | 做什么 |
|---|---|
| 早晨 | 退房、检查护照/充电器/行李，前往 Barcelona Sants |
| 车站 | 看车次、站台、座位和行李位置；长途车上只休息和补水 |
| 抵达 | Granada车站/住宿接驳，先寄存或入住 |
| 傍晚 | Cathedral、Royal Chapel、Gran Vía平地短线；最多60–90分钟 |
| 晚间 | 买早餐、确认Alhambra票面时段和入口；不走Albaicín长坡 |

若车次晚点、天气恶劣或入住不顺，D4只剩住宿和晚餐；不要用平地短线换掉睡眠。

### D5｜1月30日：Alhambra专门日

- 出发前：确认 Nasrid Palaces 票面时段、证件、入口、交通和返回路线。
- 进入后：先完成 Nasrid，再根据体力在 Alcazaba/Charles V、Partal、Generalife 中最多选一个区域。
- 中途：补水、坐下、保暖；冬季山坡风和石板路按低温/湿滑处理。
- 傍晚：回 Granada 中心，晚餐优先平地、少换乘的店。
- 任何迟到：保 Nasrid 核心，删除其他园区；不把第二天 Seville转场挤晚。

### D6｜1月31日：Granada → Seville

- 早晨：退房、确认车站和住宿地址，乘白天 Renfe/ALSA。
- 抵达：先到 Seville 住宿，寄存/入住、补水和充电。
- 有余力且天气好：Plaza de España/María Luisa 60–90分钟，拍拱廊和瓷砖。
- 晚到或下雨：只在住宿附近吃饭，提前准备 D7 Alcázar/Cathedral。

### D7｜2月1日：Alcázar → Cathedral

- 上午：Alcázar 预约或开门后尽早进入；花园、庭院按体力取舍。
- 午后：Cathedral；Giralda 登塔只有在体力、排队和开放规则允许时进行。
- 傍晚：Santa Cruz 小巷或回住宿二选一；不再强塞 Triana、河岸和屋顶。
- 雨天：先保留两个室内建筑核心，户外线全部可删。

### D8｜2月2日：Seville → Barcelona返程定位

| 时间 | 做什么 | 备注 |
|---|---|---|
| 起床后 | 检查床下、护照、充电器和行李；早餐 | 不安排景点 |
| 退房后 | 前往 Sevilla Santa Justa，乘白天长途交通 | 不买最后一班；保留可改退条件 |
| 抵达后 | Barcelona Sants→返程住宿，确认2/3去BCN路线 | 住宿优先Sants/机场交通便利处 |
| 晚间 | 住宿附近吃饭，整理行李，设闹钟 | 不进入市中心观光 |

铁路不可执行时才比较 SVQ→BCN 航班；独立票不与国际段视为联程保障。

### D9｜2月3日：Barcelona机场返程

- 起床后：检查床下、保险箱、冰箱、护照和手机。
- 起飞前约4–5小时：按最终起飞时间从返程住宿出发。
- 起飞前约3小时：到 BCN 对应航站楼，值机、托运、核对行李条和 Dubai 转机安排。
- 登机前：只按 Emirates/Aena 当前指引行动；不安排 Barcelona 观光、购物或临时跨城。
